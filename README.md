# 诺基亚 3310 《Space Impact》 (空间冲击) C++ 复刻版

基于 C++17 与 Windows Console API 实现的经典诺基亚 3310 手机游戏《Space Impact》全功能复刻版。

---

## 游戏亮点与特性

- 📱 **诺基亚 3310 复古 LCD 拟真渲染**：采用 84x48 点阵双缓冲区（Double Buffering）渲染技术，在控制台窗口内完整呈现诺基亚 LCD 液晶屏画质与手机按键外壳！
- 🚀 **丰富射击玩法机制**：
  - 支持玩家飞船 4 向灵活平滑平移。
  - **武器升级**：拾取 `P` 道具可升级激光（单发激光 ➔ 双重激光 ➔ 散弹等离子炮）。
  - **清屏特种弹**：按下 `K` 或 `B` 键发射空间震荡波，瞬间消灭全屏敌弹并对敌机造成高额伤害。
  - **道具拾取**：敌机击毁后概率掉落 `P` (武器升级)、`H` (生命恢复)、`B` (清屏炸弹补给)。
- 👾 **多元敌机与 Boss 战**：
  - 侦察机（正弦波巡航轨迹）、重型轰炸机（发射子弹反击）、截击机（急速冲刺）。
  - **关卡 Boss 战**：关卡末尾触发巨型宇宙母舰 Boss 战，具备多段攻击形态与血条显示。
- 🔊 **复古单音/多音音效系统**：内置开火、爆炸、清屏炸弹与 Boss 出现音效（基于 Windows `Beep` API）。
- 🏆 **最高分自动保存**：自动记录与持久化本地最高得分。

## 游戏操作指南

| 动作 | 键盘按键 |
|---|---|
| **飞船移动** | `W` / `A` / `S` / `D` 或 `↑` / `↓` / `←` / `→` |
| **常规激光开火** | `J` 或 `Space` (空格键) |
| **特种清屏炸弹** | `K` 或 `B` |
| **暂停 / 继续** | `P` |
| **返回主菜单 / 退出**| `ESC` |

## 编译与运行方式

### 方式 1：使用一键编译脚本 (推荐)
双击运行 `build.bat` 或在终端中执行：
```cmd
build.bat
```
编译成功后将自动生成 `SpaceImpact.exe`，直接运行即可畅玩！

### 方式 2：使用 Visual Studio 2022
双击打开 `SpaceImpact.sln`，在 VS 2022 中直接点击 **Local Windows Debugger (本地 Windows 调试器)** 即可编译与运行。

### 方式 3：手动使用 MSVC 命令行
在 Developer Command Prompt for VS 2022 中运行：
```cmd
cl /EHsc /O2 /std:c++17 SpaceImpact.cpp user32.lib gdi32.lib winmm.lib
SpaceImpact.exe
```
